# 2.3.3 — instrucción opcional desde el recorte

Botón «Dar instrucción» junto a los controles de recorte. Abre un campo opcional de hasta 2000 caracteres, precargado con las instrucciones del apartado Foto. «Recortar y leer» aplica el contenido del campo al prompt de reconocimiento; Cancelar no modifica las instrucciones anteriores. El campo puede quedar vacío y las fotos siguen solo en memoria.

Once pruebas unitarias y build aprobados. Navegador con reconocimiento simulado: seleccionar de galería, abrir Dar instrucción, escribir indicación y verificar que se envía exactamente en la solicitud al reconocer. El flujo de revisión de canciones sigue funcionando; no se hicieron llamadas de IA reales para esta prueba.
